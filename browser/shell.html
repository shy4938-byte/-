01 · PDF 데이터시트 추가 0개 PDF

여러 파일과 여러 모델을 비교할 수 있습니다. 파일은 외부로 전송하지 않습니다.
앱을 불러오는 중…
Chrome 또는 Edge 최신 버전을 권장합니다. 스캔 PDF의 OCR과 암호 해제는 지원하지 않습니다. 자동 추출한 값은 원문 확인 후 사용하세요.

02 · SSD 스펙 비교 0개 제품

값을 직접 수정할 수 있습니다. 비교표에는 최대 속도를 표시합니다. 성능 측정 조건(QD·TurboWrite)은 제품마다 다를 수 있습니다. 상세에서 확인하세요. 노랑: 제품 간 차이 · 연분홍: 확인 필요 · 초록: 확인 완료. 한 그룹에 4개 제품을 표시합니다.

03 · 원문 근거와 추가 사양

값을 클릭하면 PDF 페이지와 추출 근거를 확인할 수 있습니다. 제품 헤더의 ‘상세’ 버튼으로 추가 사양을 볼 수 있습니다.
첨부받은 원본 엑셀 양식이 앱에 포함되어 있습니다. 선택한 제품군 시트의 C~F열만 입력하며 다른 시트와 서식·수식·인쇄 설정을 유지합니다.
브라우저는 종료 시 분석 결과를 보관하지 않습니다. 종료 전에 Excel로 저장하세요.
