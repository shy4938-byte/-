# SpecCompare HTML 앱

`SpecCompare.html`을 Chrome 또는 Edge 최신 버전으로 여세요. 인터넷, 서버, Python, EXE 설치 없이 사용합니다.

1. MEMORY/SSD/VGA를 선택합니다.
2. PDF를 추가하고 ‘스펙 분석’을 누릅니다.
3. 여러 모델이 있으면 비교할 모델을 선택합니다.
4. 결과를 확인·수정하고 ‘현재 그룹 엑셀 저장’을 누릅니다.

4개를 초과한 제품은 비교 그룹으로 나뉩니다. 그룹별로 Excel을 저장하세요. 포함된 원본 양식의 해당 시트 C~F열만 수정합니다. 다른 시트와 ZIP 구성요소는 원본 바이트를 유지합니다.

PDF는 외부로 전송하지 않습니다. 라이브러리와 Excel 템플릿이 HTML 안에 들어 있습니다. 종료하면 분석 결과가 사라지므로 먼저 Excel로 저장하세요. 내려받은 Excel은 브라우저 다운로드 목록에서 열면 됩니다.

텍스트 PDF의 ‘항목: 값’, 명확한 모델/용량 표, 모델 헤더 표를 규칙으로 분석합니다. Samsung PM9E1 Rev 1.3 실제 PDF로 검증했습니다. 모든 제조사 PDF를 지원하는 것은 아니며 복잡한 레이아웃은 수동 확인이 필요합니다. 스캔 OCR과 암호 해제는 지원하지 않습니다.

개발 빌드: Node.js 22+에서 `npm ci --prefix browser` 후 `npm run build --prefix browser`. 결과: browser/dist/SpecCompare.html.

테스트는 TEST_REPORT.md를 참조하세요. 실제 사용자 PC의 브라우저 정책이나 오래된 브라우저에서는 실행이 제한될 수 있습니다.

## 1.1.1 표시 수정
Samsung PM9E1 데이터시트는 모델명에 제조사·제품군·용량을 표시합니다(예: Samsung PM9E1 512GB). 기존 Part Number는 상세의 ‘부품번호’로 보존합니다. 표지의 제품군과 품번을 함께 확인할 수 있는 문서에만 적용하며 임의로 추정하지 않습니다.

## 1.1.2 PM9A1 분석 보완
줄바꿈·병합된 성능표의 레이블/수치/단위 위치를 연결합니다. PM9A1 표지의 제품군명과 Gen4 표기도 인식합니다. 성능의 슬래시 병기값을 모두 보존하고 QD를 표시합니다. 랜덤 성능은 QD32 값을 기본 표에 표시하고 QD1 값은 상세정보로 분리합니다. 순차 성능 두 번째 값은 주석 5에 따라 TurboWrite 미적용이며 랜덤 병기값의 추가 조건은 임의 추정하지 않습니다. 전부 미확인인 제품은 자동으로 추가하지 않습니다.

PM9E1·PM9A1을 같은 용량으로 비교하려면 각 PDF의 모델 선택 창에서 원하는 용량만 체크하세요(예: 각각 512GB). 전체 모델 선택 시 8개 제품이 두 비교 그룹으로 나뉩니다.

## 1.1.3 최대 속도 표시 통일
비교표와 Excel의 순차/랜덤 속도에는 원문 최대 수치와 단위만 표시합니다. 측정 QD, QD별 원문 병기값, TurboWrite 미적용 속도는 상세정보로 분리합니다. PM9A1 순차 성능의 두 번째 값은 주석 5에 근거해 TurboWrite 미적용으로 표시하며, 해당 수치가 없는 PM9E1은 확인 필요로 유지합니다. 서로 다른 측정 조건의 성능값은 완전히 동등한 시험 결과를 의미하지 않습니다.
