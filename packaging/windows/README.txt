SpecCompare Windows v1.2.0 · 무료 로컬 AI (64-bit)

API 키·API 요금 없이 이 PC에서 분석합니다. 유료 온라인 API는 연결하지
않고 클라우드 모델도 차단합니다. Python/Git/VS Code 설치는 불필요합니다.

처음 한 번:
1. ZIP 전체 압축 해제 → SpecCompare.exe 실행.
2. 무료 AI 연결 설정 → 무료 Ollama 설치 → 설치 후 실행.
3. qwen2.5vl:3b → 무료 모델 받기 → 완료 후 연결 확인 → 설정 적용.
4. PDF 추가 → 스펙 분석 → 모델 선택 → 원문·단위·조건 확인 및 수정.
5. Excel 저장: 원본 비교표 + _분석근거.xlsx(공통 최대값·원문 근거) 저장.

Ollama 로컬 사용은 계정·카드·유료 구독이 필요하지 않습니다. 처음 수 GB
모델 다운로드에 인터넷·디스크 공간이 필요합니다. AI 모델은 ZIP에 포함하지
않습니다. RAM 16GB 이상을 권장하며 CPU에서는 느릴 수 있습니다.
기본 3b는 가벼운 시작 모델, 7b는 더 높은 성능의 PC용 선택입니다.

AI/OCR 결과는 오류가 있을 수 있으므로 반드시 원문을 확인하세요.
공통 최대값은 모델별 확정값으로 복사하지 않습니다. 원본 Excel 양식 유지,
가운데 정렬, 별도 근거 파일 저장을 지원합니다. 영어·한국어 OCR 포함.

AI 오류 때 규칙 추출로 자동 대체하지 않습니다. 빠른 추출은 직접 선택하며
지원하지 않는 양식이 있습니다. 한 번에 최대 100페이지/글자 30만 자이고
AI 문맥 한도를 넘으면 분할 안내를 표시합니다. _internal/templates를 보존하세요.

빌드 환경에 실제 Ollama 모델이 없어 실제 LLM 해석 정확도·속도는 미검증입니다.
Windows의 AI 테스트 서버는 고정 응답을 반환하는 합성 계약 테스트입니다.
모델 설치 후 실제 문서와 대조하세요. 모든 PDF의 완벽한 처리를 보장하지 않습니다.
