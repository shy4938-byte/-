SpecCompare Windows v1.1.1 (64-bit)

1. ZIP 전체 압축 해제 → SpecCompare.exe 실행. Python/Git 설치 불필요.
2. AI 연결 설정에서 로컬 Ollama 설치·실행 및 qwen2.5vl:7b 모델 다운로드.
   또는 온라인 OpenAI API 모델·키 입력 및 PDF 글자/이미지 전송 동의.
3. PDF 추가 → AI 문서 해석 → 스펙 분석 → 모델 선택.
4. 원문 페이지/인용/모델 연결/측정 조건 확인 후 수정.
5. Excel 저장: 원본 비교 양식 + _분석근거.xlsx(공통 최대값·근거) 저장.

AI 모델은 포함하지 않습니다. 로컬 모델 최초 다운로드에는 인터넷과 수 GB 공간이
필요하며 RAM 약 16GB 이상을 권장합니다. CPU에서는 느릴 수 있습니다.
온라인 AI는 PDF 글자·페이지 이미지를 전송하고 API 비용이 발생할 수 있습니다.
API 키는 이번 실행의 메모리에만 보관하며 파일에 저장하지 않습니다.

AI 없이 기존 규칙 추출은 빠른 추출 모드를 직접 선택하세요. AI 오류 때 자동으로
규칙으로 대체하지 않습니다. 새 양식마다 규칙 업데이트가 필요한 한계를 줄이지만
모든 문서의 정확한 처리를 보장하지는 않습니다. AI 값은 반드시 원문을 검토하세요.

영어·한국어 OCR 데이터 포함. _internal 및 templates를 삭제하지 마세요.
암호화 문서는 해제 후 사용. 한 번에 최대 100페이지/텍스트 30만 자.
공통 최대값을 모델별 확정값으로 복사하지 않으며 별도 근거 파일에 보존합니다.

실제 LLM 정확도는 이 빌드 환경에 모델/API 키가 없어 미검증입니다.
Windows 빌드의 AI 테스트 서버는 고정 응답을 반환하는 합성 계약 테스트입니다.
모델 설정 후 실제 문서와 결과를 대조하세요.
