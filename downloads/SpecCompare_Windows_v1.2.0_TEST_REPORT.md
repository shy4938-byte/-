# SpecCompare Windows v1.2.0 · 무료 로컬 AI 검증

사용자의 최종 조건(추가 요금 없음)에 따라, 유료 온라인 API를 앱 화면 및 실행 경로에서 제거했습니다.

- 기본 로컬 Ollama 비전 모델 qwen2.5vl:3b. 선택 7b.
- API 키 입력 없음. 유료 제공자 지정 및 cloud 모델 이름 차단.
- PDF를 보내기 전에 Ollama 모델 정보를 조회해 원격 모델/비전 미지원 모델 차단.
- PDF 글자·이미지를 이 PC의 loopback HTTP 주소로만 전송. 외부 서버 주소 거절.
- 최초 무료 Ollama 설치 및 수 GB 모델 다운로드 필요. AI 모델은 ZIP에 미포함.
- 영어·한국어 OCR 언어 데이터 포함. 한글 경로의 OCR 데이터는 내용 해시를 확인한 TEMP 캐시로 읽음.
- 모델별 원문 인용·숫자·단위·적용 범위 검사. 근거 없는 공통 최대값을 모델 셀로 복사하지 않음.
- 모델 목록을 전체 문서에서 분할 해석 후 페이지별 이미지 해석. 문맥/출력 한도 초과 시 오류로 안내.
- 원본 Excel 비교표 + _분석근거.xlsx(제품군 공통·미확정/페이지/조건/근거) 저장.

테스트: 전체 46개 대상, 사용자 실문서 6개는 CI에서 미첨부로 건너뜁니다. AI provider 계약 서버는 실제 모델이 아니라 정해진 응답을 반환하는 합성 서버입니다.

실문서 회귀: PM9E1, PM9A1, 990 PRO, ESSENCORE, Samsung DDR5. Transcend는 사람이 구성한 후보의 원문 인용과 공통 최대값 분리를 검증하며 실제 AI 해석 정확도를 테스트한 것은 아닙니다.

미검증: 실제 Ollama 모델의 사용자 문서 해석 정확도·속도, 사용자 PC의 모델 설치/다운로드/하드웨어 성능, 모든 PDF 양식, 실제 VGA 문서, 한국어 OCR 정확도, 일반 사용자 Windows/SmartScreen 및 Microsoft Excel UI.

API 요금은 없지만 하드웨어에 따라 처리 속도와 정확도에 제약이 있습니다. 모든 문서를 완벽하게 처리한다고 보장하지 않습니다.
