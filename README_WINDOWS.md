# SpecCompare Windows v1.2.0 · 무료 로컬 AI

PDF의 글자·표·페이지 이미지를 AI가 해석하고, 모델별 사양과 공통 최대값을 구분합니다.
**API 키와 API 이용 요금이 필요 없습니다. 유료 온라인 API와 클라우드 모델 연결은 차단합니다.**

## 다운로드

[최신 배포 안내](downloads/SpecCompare_Windows_README.md) · [Windows 빌드](https://github.com/shy4938-byte/-/actions/workflows/build-speccompare.yml)

배포 완료 후 실제 URL·해시는 downloads/SpecCompare_Windows_v1.2.0.json에 기록됩니다.
50 MiB를 넘는 ZIP은 GitHub Releases에 게시합니다. 이전 파일과 다른 앱은 보존합니다.

## 처음 한 번: 무료 AI 설치

1. ZIP 전체 압축 해제 → SpecCompare/SpecCompare.exe 실행.
2. **무료 AI 연결 설정 → 무료 Ollama 설치**를 눌러 Windows용 Ollama를 설치하고 실행합니다.
3. 기본 모델 **qwen2.5vl:3b → 무료 모델 받기**를 누릅니다. 수 GB를 내려받으므로 시간이 걸립니다.
4. **연결 확인 → 설정 적용** 후 PDF를 추가하고 **스펙 분석**을 누릅니다.

Ollama의 로컬 사용은 계정·카드·유료 구독이 필요 없습니다. 클라우드 플랜을 선택할 필요도 없습니다.
처음 설치·모델 다운로드에는 인터넷과 디스크 공간이 필요하며 이후 로컬 분석은 이 PC에서 수행합니다.
Python, Git, VS Code는 필요하지 않습니다. AI 모델 자체는 ZIP에 포함하지 않습니다.

3b는 가벼운 시작 모델이며 7b는 더 높은 성능의 PC용 선택입니다. RAM 16GB 이상을 권장합니다.
RAM·GPU·문서 길이에 따라 속도와 해석 품질이 달라집니다. CPU에서는 느릴 수 있습니다.
고성능 PC가 없고 추가 요금도 사용할 수 없다면 AI 분석의 속도·정확도에는 제약이 있습니다.

## 결과·Excel 저장

- MEMORY / SSD / VGA는 분석 힌트입니다. 결과의 제품군을 판별해 해당 비교 표로 전환합니다.
- 원문 페이지·인용·모델 연결·측정 조건을 확인하고 셀 값을 수정할 수 있습니다.
- AI 값은 모두 검토 필요 상태입니다. 인용의 존재·단위 검사는 의미 해석의 정확성을 보장하지 않습니다.
- 용량별 근거가 없는 제품군 최대 성능·내구성은 모델 셀에 복사하지 않고 하단 공통·미확정 영역에 표시합니다.
- Excel 저장: 원본 양식의 비교표 + 별도 **_분석근거.xlsx**(공통·미확정 값/페이지/조건/인용)를 저장합니다.
- 원본 양식은 보존하고 가운데 정렬합니다. 4개를 넘는 모델은 비교 그룹별로 저장합니다.

## OCR·처리 한도

영어·한국어 Tesseract fast 데이터를 포함합니다. 텍스트가 없거나 매우 적은 스캔 페이지는 OCR로 읽고, AI에는 페이지 이미지도 제공합니다.
OCR 숫자·단위는 오인식할 수 있습니다. 암호화 PDF는 해제 후 사용하세요.
모델 목록은 문서 전체를 크기에 따라 나누어 읽고, 페이지 이미지는 한 페이지씩 해석합니다.
최대 100페이지/텍스트 30만 자이며 로컬 모델의 보수적인 문맥 한도를 넘으면 더 짧게 분할하라는 오류를 표시합니다.
일부 페이지를 생략해 성공으로 표시하지 않습니다.

## 오류 확인

- 연결 실패: Ollama가 실행 중인지, 모델이 설치되어 있는지 확인하세요.
- 기본 주소는 http://127.0.0.1:11434 입니다. 다른 PC나 인터넷 서버 주소는 허용하지 않습니다.
- 모델 이름에 cloud가 있거나 Ollama가 원격 모델이라고 보고하면 분석을 차단합니다.
- 페이지 이미지·JSON을 지원하는 로컬 비전 모델이 필요합니다.
- AI 실패 시 기존 규칙으로 자동 대체하지 않습니다. AI 없이 사용하려면 **빠른 추출**을 직접 선택하세요. 이 모드는 양식 지원 범위가 제한적입니다.
- _internal, templates 폴더를 삭제하지 마세요. 한글 경로에서 OCR 언어 데이터를 읽을 수 있도록 해시 검증 캐시를 사용합니다.

## 검증·한계

단위/GUI/OCR/HTTP 계약 테스트와 실제 LLM의 해석 정확도는 구분합니다.
테스트 서버는 정해진 응답을 반환하는 합성 서버로 실제 AI 모델이 아닙니다.
빌드 환경에 실제 Ollama 모델이 없어 **실제 LLM으로 사용자 PDF를 해석한 정확도·속도는 미검증**입니다.
모든 PDF 양식을 100% 정확히 처리한다고 보장하지 않습니다. 모델 설치 후 원문 대조가 필요합니다.

OCR 데이터: https://github.com/tesseract-ocr/tessdata_fast (eng, kor), Apache-2.0. assets/ocr/LICENSE 및 NOTICE.txt 참고.
