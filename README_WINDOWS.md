# SpecCompare Windows v1.1.1

다양한 PDF 양식을 글자·표·페이지 이미지로 해석하는 AI 분석 모드와 내장 OCR을 추가했습니다.
기존 규칙 추출도 별도 모드로 유지합니다. Python, Git, VS Code 설치는 필요하지 않습니다.

## 다운로드

[최신 배포 안내](downloads/SpecCompare_Windows_README.md) · [빌드 결과](https://github.com/shy4938-byte/-/actions/workflows/build-speccompare.yml)

성공한 배포의 실제 URL·해시는 downloads/SpecCompare_Windows_v1.1.1.json에 기록됩니다.
50 MiB를 넘는 ZIP은 GitHub Releases에 게시합니다. 이전 배포 및 다른 앱은 보존합니다.

## 처음 실행: AI 연결을 한 번 설정하세요

AI 모델 자체는 ZIP에 포함하지 않습니다. OCR 언어 데이터와 앱 실행 라이브러리는 포함합니다.

### 로컬 AI (기본)

1. ZIP 전체 압축 해제 후 SpecCompare/SpecCompare.exe 실행.
2. AI 연결 설정 → Ollama 설치 페이지에서 Windows용 Ollama를 설치하고 실행.
3. 기본 모델 qwen2.5vl:7b로 **로컬 모델 받기** → 완료 후 **연결 확인** → **설정 적용**.
4. PDF 추가 → AI 문서 해석 모드 → 스펙 분석.

최초 수 GB 모델 다운로드에 인터넷·디스크 공간이 필요합니다. 이후 로컬 분석은 PDF를 외부로 전송하지 않습니다.
RAM 약 16GB 이상을 권장하며 GPU/PC 성능·문서 길이에 따라 시간이 크게 달라집니다.
연결 주소는 이 PC의 loopback HTTP만 허용합니다. Ollama의 이미지+JSON 지원 비전 모델이 필요합니다.

### 온라인 AI (선택)

AI 연결 설정에서 OpenAI API 선택 → 이미지/구조화 출력을 지원하는 모델(기본 gpt-4.1-mini)과 본인의 API 키 입력 → 전송 동의 → 설정 적용.
선택 PDF의 추출 글자 및 페이지 이미지가 OpenAI로 전송되고 API 요금이 발생할 수 있습니다.
앱은 Responses API에 store=false를 지정하지만 제공자의 별도 보관 정책을 대체하지 않습니다.
API 키는 이번 앱 실행의 메모리에만 보관하고 설정 파일·로그에 저장하지 않습니다. 다음 실행에는 다시 입력해야 합니다.

## 결과 확인·Excel 저장

- MEMORY / SSD / VGA 힌트보다 AI가 판별한 제품군을 사용합니다. 다른 제품군은 나누어 분석합니다.
- 모델·값마다 PDF 페이지와 원문 인용을 확인하세요. 모델 연결의 근거도 표시합니다.
- AI 후보는 모두 검토 필요 상태입니다. 인용의 존재·단위 검사는 의미 해석의 정확성을 보증하지 않습니다.
- 모델별 근거 없는 최대 성능·내구성은 모델 셀에 복사하지 않고 하단 **제품군 공통·미확정** 영역에 표시합니다.
- 셀 수정 가능. Excel 저장은 기존 원본 양식을 보존하고 가운데 정렬합니다.
- AI 결과 저장 시 **비교표.xlsx**와 **비교표_분석근거.xlsx**를 만듭니다. 후자의 공통·미확정 시트에서 공통 최대값·페이지·조건을 확인합니다.
- 4개를 넘는 모델은 비교 그룹별로 저장합니다.

## OCR·문서 처리

영어·한국어 Tesseract fast 언어 데이터를 포함합니다. 텍스트가 없거나 매우 적은 스캔 페이지는 내장 OCR로 읽고, AI에는 페이지 이미지도 전달합니다.
OCR은 오인식할 수 있습니다. 암호화 PDF는 해제 후 사용하세요.
문서를 요약해 일부 페이지를 몰래 생략하지 않습니다. 한 번에 최대 100페이지/추출 글자 30만 자이며 초과하면 나누어 분석하라는 오류를 표시합니다.
모델 목록은 전체 문서를 크기에 따라 나누어 해석하고, 이미지는 로컬 1페이지/온라인 2페이지씩 분석합니다. 여러 번의 AI 요청이 발생합니다. 로컬 요청이 보수적인 문맥 크기를 넘으면 생략하지 않고 분할 안내 오류를 표시합니다.

## 오류 확인

- AI 연결 실패: 로컬 Ollama 실행·모델 다운로드, 또는 온라인 키·잔액·인터넷을 확인하세요.
- 모델이 이미지/JSON을 지원하지 않거나 응답이 잘리면 다른 비전 모델·짧은 문서로 재시도하세요.
- AI 실패 시 규칙 추출로 자동 대체하지 않습니다. 빠른 추출 모드는 사용자가 직접 선택합니다.
- PDF를 프롬프트로 취급하지 않도록 지시하고, 인용 없는 값과 일부 모호한 모델 연결을 보류합니다. 완전한 오류 방지 장치는 아닙니다.
- _internal, templates 폴더를 삭제하지 마세요. 일반 사용자 PC·보안 경고의 실측 범위는 검증 보고서를 확인하세요.

## 검증 범위

단위/GUI/HTTP 계약 테스트와 실제 LLM 해석 정확도는 구분합니다. 테스트 서버는 정해진 응답을 반환하는 합성 서버로, AI 모델이 아닙니다.
배포 환경에 실제 Ollama 모델/API 키가 없어 **실제 LLM으로 사용자 PDF를 해석한 정확도는 미검증**입니다.
모든 PDF 양식을 100% 정확히 처리한다고 보장하지 않습니다. 사용자 모델 설정 후 원문 대조가 필요합니다.

OCR 데이터: tesseract-ocr/tessdata_fast의 eng.traineddata, kor.traineddata (Apache-2.0). assets/ocr/LICENSE 및 NOTICE.txt 참고.
